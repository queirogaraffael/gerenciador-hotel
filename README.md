## Como Executar
* Clone o repositório para sua máquina local.
* Abra o projeto em sua IDE Java.
* Certifique-se de ter configurado corretamente o banco de dados Postgres e as credenciais de acesso no arquivo persistence.xml.
* Execute o projeto a partir da classe Main.
